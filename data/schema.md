# Data schema

All files are UTF-8 CSV with a header row. Facts are stored at the level where they are true:

```
providers.csv   organisation: seat, control, owners, Code of Practice, official namespaces
   └─ families.csv   model family: origin, licence, data, compute, AI Act summary
         └─ scorecard.csv   model: repo, modalities; empty family fields inherit
sources.csv     one row per fact, at the scope where the source states it
```

Curated by hand and reviewed in pull requests: `providers.csv`, `families.csv`, `scorecard.csv`,
`sources.csv`, `mlx_builds.csv`. Generated by scripts, do not edit by hand: `hf_facts.csv`,
`mlx_support.csv`, `hf_namespaces.csv`, and the `archive_url` column of `sources.csv`.

## `providers.csv`

| Column | Allowed values | Meaning |
|---|---|---|
| `id` | `a-z0-9-` | Stable identifier |
| `name` | text | Organisation name |
| `country` | ISO 3166-1 alpha-2 | Seat |
| `region` | `eu`, `europe`, `non-europe` | `europe` = European but outside the EU/EEA (CH, NO, UK, ...) |
| `control` | `independent`, `acquired-non-eu`, `merger-pending-non-eu` | Ownership |
| `majority_owner` | text | Required unless `independent` |
| `cop_signatory` | `yes`, `no`, `unknown` | Signed the EU GPAI Code of Practice |
| `hf_orgs` | `;`-separated | The provider's official Hugging Face organisations |
| `github_orgs` | `;`-separated | Official GitHub organisations |
| `domains` | `;`-separated | Official web domains |
| `notes` | text | |

`hf_orgs`, `github_orgs` and `domains` decide whether a source or an MLX build counts as published
by the provider itself.

## `families.csv`

| Column | Allowed values | Meaning |
|---|---|---|
| `id` | `a-z0-9.-` | Stable identifier |
| `name` | text | Family name |
| `provider_id` | id in `providers.csv` | |
| `origin` | `scratch`, `continued-own`, `continued-european`, `finetune-european`, `continued-foreign`, `finetune-foreign` | `own` = the provider's earlier model; `foreign` = a non-European base |
| `base_model` | text | Base model, if any |
| `license_class` | `osi`, `osi-aup`, `custom`, `nc`, `unclear` | `osi` = Apache-2.0, MIT, CC-BY(-SA) and similar; `osi-aup` = plus a binding use policy |
| `data` | `open`, `documented`, `undisclosed`, `unknown` | `open` = training data published; `documented` = mix described |
| `compute` | `eu`, `europe`, `non-europe`, `unknown` | Where pre-training ran |
| `ai_act_summary` | `yes`, `no`, `unknown` | Public summary of training content under the EU AI Act |
| `notes` | text | |

## `scorecard.csv` (models)

| Column | Meaning |
|---|---|
| `id` | Stable identifier (`a-z0-9.-`) |
| `name` | Display name |
| `hf_repo` | Original release on the Hub (`org/name`) |
| `family_id` | id in `families.csv` |
| `modalities` | Comma-separated: `text`, `image`, `audio` |
| `origin` … `ai_act_summary` | Optional overrides of the family values; empty = inherit. An override needs a source at model scope |
| `hbd_involvement` | Our own work on this model (disclosure) |
| `notes` | Anything a reader must know |

## `sources.csv`

| Column | Allowed values | Meaning |
|---|---|---|
| `scope` | `provider`, `family`, `model` | Level the fact belongs to |
| `subject` | id at that level | |
| `field` | column name | e.g. `control`, `cop_signatory`, `provider_id`, `origin`, `data`, `compute`, `license_class` |
| `url` | `https://...` | Where the fact can be checked |
| `issuer` | `provider`, `official`, `academic`, `press`, `community`, `hbd` | Who published the source (see below) |
| `checked` | `yes`, `no` | We read the source and it states the fact |
| `retrieved` | `YYYY-MM-DD` | When we read it |
| `archive_url` | Wayback snapshot | Filled by `scripts/archive_sources.py` |
| `note` | text | What the source says, in a few words |

### Issuers

| Issuer | Meaning | Examples |
|---|---|---|
| `provider` | The model maker itself | Model card in the provider's own Hub organisation, its website, its technical report, its licence file |
| `official` | Public authority or official document | European Commission lists, stock-exchange filings, court rulings |
| `academic` | Scholarly publication by third parties | Papers, benchmark studies |
| `press` | Editorial media | heise, Reuters, SiliconANGLE |
| `community` | Individuals or third parties without editorial control | Personal Hub accounts, blogs, forums, community conversions |
| `hbd` | Our own measurement | Load check, KL divergence |

`validate.py` derives the issuer from the URL where it can (official and press hosts, the provider's
`hf_orgs`, `github_orgs` and `domains`, other Hub namespaces) and fails if the stated issuer
disagrees. Only `provider`, `official`, `academic` and `press` sources with `checked = yes` count
for the tier.

## `mlx_builds.csv`

| Column | Meaning |
|---|---|
| `id` | Model id |
| `repo` | MLX build on the Hub |
| `bits` | Bits per weight (effective average for mixed builds) |
| `note` | |

The publisher of a build is derived, not stored: `official` (the provider's own organisation),
`hbd` (here be dragons), `curated` (mlx-community, lmstudio-community), `organisation` (any other
organisation), `individual` (a personal account), in that order of trust.

## Generated files

- `hf_facts.csv` (`scripts/fetch_hf_facts.py`): licence, gating, parameters, architecture, context,
  creation date, model-card lines about compute and data.
- `hf_namespaces.csv` (`scripts/classify_namespaces.py`): whether each cited Hub namespace is an
  organisation or a user, and whether the Hub has verified it.
- `mlx_support.csv` (`scripts/check_mlx_support.py`): whether mlx-vlm loads the checkpoint,
  checked from `config.json` and safetensors headers, with the mlx-vlm revision.

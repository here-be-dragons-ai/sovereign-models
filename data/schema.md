# Data schema

All files are UTF-8 CSV with a header row. `data/scorecard.csv` and `data/sources.csv` are
curated by hand and reviewed in pull requests. `data/hf_facts.csv` and `data/mlx_support.csv`
are generated by scripts; do not edit them by hand.

## `data/scorecard.csv` (one row per model)

| Column | Allowed values | Meaning |
|---|---|---|
| `id` | lowercase, `a-z0-9.-` | Stable identifier, used to join the other files |
| `name` | text | Display name |
| `hf_repo` | `org/name` | Original release on the Hugging Face Hub |
| `provider` | text | Who trained and released the model |
| `provider_country` | ISO 3166-1 alpha-2 | Seat of the provider |
| `region` | `eu`, `europe`, `non-europe` | `europe` = European but outside the EU/EEA (CH, NO, UK, ...) |
| `control` | `independent`, `acquired-non-eu`, `merger-pending-non-eu` | Ownership of the provider |
| `origin` | `scratch`, `continued-own`, `continued-european`, `finetune-european`, `continued-foreign`, `finetune-foreign` | How the weights came about; `own` = the provider's earlier model, `foreign` = a non-European base model |
| `base_model` | text | Base model, if any |
| `license_class` | `osi`, `osi-aup`, `custom`, `nc`, `unclear` | `osi` = Apache-2.0, MIT, CC-BY(-SA) and similar; `osi-aup` = such a licence plus a binding use policy; `custom` = the provider's own licence; `nc` = non-commercial |
| `data` | `open`, `documented`, `undisclosed`, `unknown` | `open` = training data published; `documented` = data mix described |
| `compute` | `eu`, `europe`, `non-europe`, `unknown` | Where pre-training ran |
| `ai_act_summary` | `yes`, `no`, `unknown` | Public summary of training content under the EU AI Act |
| `cop_signatory` | `yes`, `no`, `unknown` | Provider signed the EU GPAI Code of Practice |
| `modalities` | comma-separated: `text`, `image`, `audio` | Input modalities |
| `hbd_involvement` | text | Our own work on this model (disclosure) |
| `notes` | text | Anything a reader must know |

## `data/sources.csv` (one row per model and field)

| Column | Meaning |
|---|---|
| `id` | Model id from `scorecard.csv` |
| `field` | Column in `scorecard.csv` the source supports |
| `url` | Where the fact can be checked |
| `status` | `primary` (provider or official document), `press` (reputable reporting), `secondary` (research summary, not checked against a primary source) |
| `retrieved` | ISO date |
| `note` | What the source says, in a few words |

Only `primary` and `press` sources count for the tier. A value backed only by a `secondary`
source is treated as `unknown` when the tier is computed.

## `data/hf_facts.csv` (generated by `scripts/fetch_hf_facts.py`)
Licence, gating, parameter count, architecture, context length and creation date from the
Hub, plus model-card lines that mention training compute or data.

## `data/mlx_support.csv` (generated by `scripts/check_mlx_support.py`)
Whether the current mlx-vlm loads the checkpoint, checked from `config.json` and safetensors
headers without downloading weights.
